# SmazLabz website

A lightweight, responsive portfolio for SmazLabz. It is plain HTML, CSS and JavaScript, with no build step, external libraries, paid services or runtime dependencies.

## Preview locally

Open `index.html` in a browser.

## Publish free with GitHub Pages

1. Open the repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then save.
4. Wait for the Pages deployment to finish. GitHub will show the published URL in the Pages settings.

For this repository, the expected address is:

https://smazlabz.github.io/sofware/

## Editing the catalogue

Edit `index.html`. Each project is an `article.card` element inside the `#grid` container. Keep the `data-cat` value aligned with one of the filter categories.

## Important

This is a curated starter portfolio, not a complete transfer of every itch.io project or game download. Check each project title, description and link before promoting the site. The original itch.io pages remain the source for downloads, purchases and release updates.

GitHub Pages hosting for a public repository is available at no charge within GitHub's published usage limits. A custom domain is optional and may cost money; no custom domain is needed for the GitHub Pages address above.
